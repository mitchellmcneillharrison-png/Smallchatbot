Tiny Chatbot — a GPT built from scratch

A ~2M-parameter decoder-only Transformer, hand-written in PyTorch and re-implemented in plain JavaScript. Trained on a small question/answer dataset — and it runs entirely in your browser, no server.

⚠️ This bot only knows what it was trained on: simple arithmetic (small numbers), greetings, a few facts about itself, and a hand-picked set of general-knowledge questions (capitals, science, etc.). Ask within that world and it answers; ask outside it and it will confidently make something up. It's a demo of the architecture, not a real assistant.

How does it work?

Every question is turned into word tokens, framed as <user> … <bot>, and fed through the same from-scratch Transformer (multi-head causal self-attention, LayerNorm, feed-forward, residuals — all hand-written). The model then predicts the answer one word at a time until it emits an end-of-answer token. The whole forward pass runs in JavaScript on your device; the trained weights ship as a static JSON file.

Runs 100% client-side. Full source, training code, and dataset are in the repository.
